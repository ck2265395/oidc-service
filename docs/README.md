## 导出和使用

- 把这四份 Markdown 一并上传给远程 ChatGPT，或放到远程仓库 docs 目录。
- 将交接说明第 2 节的任务指令发送给能够操作该仓库的开发会话。
- 如需续做本地已有骨架，另行提交源码和锁文件；这份文档包不包含源码、依赖、密钥或生产配置。
- 仓库根已经是 oidc-service 时，不要重复嵌套同名目录。
- 文档内部使用相对链接，导出后仍可以一起阅读。

## 已确认决策

复用已有用户、独立 OIDC、只读账号库；原版 oidc-provider 加自研外围；面向自有和外部合作应用；开发者申请加审核；移动 App 与 Web；中英文；第三方自行维护账号及登录态；首期不接社交登录、不签刷新令牌、不打通旧 Cookie。

## 补充默认值

开发计划为可执行交接而补充了门户采用内置第一方 OIDC 客户端、server-rendered 页面、管理员会话期限、限流阈值、分页上限、审计保留期，以及原生示例默认 Flutter。这些是实施默认值，不表示用户在对话中逐项确认过；若目标仓库已有成熟替代方案，实施者应记录等价替换及理由，保持产品和安全验收不变。
